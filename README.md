The full-size master photos (`originals/`) are deliberately **not** in this repo.

## Story conventions

## Episodes and panels

What the menu calls an **Episode** is one folder in `scenes/` (for example
`scenes/sc05-uber/`). Each episode plays several **panels** (pictures from
the book) one after another. ("Scene" in folder names and code means the
same thing as episode.)

Rules we keep across every episode, so the story feels consistent:

- **The van travels LEFT to RIGHT** when it's going somewhere (the opening, and its return in episode 2).
- **RIGHT to LEFT is reserved** for a comedy "retreat" later in the story. Don't use it for anything else.
- **The taxis drive in from the RIGHT** (episode 4), because they're drawn facing left and must come in nose first (Enda's call). The plane may fly both ways. In episode 6 the chickens run right to left (Enda's call).
